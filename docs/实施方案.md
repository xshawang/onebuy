# Superbuy 前端仿站 —— 实施方案

## 1. 项目范围
基于 `html/` 目录中已抓取的静态页面，仿造 [Superbuy](https://www.superbuy.com/) 构建一个纯前端交互站点。所有后端接口均由本地 Mock 层（MSW）拦截返回，无真实后台。

共计 5 个页面：首页、商品详情、打包方案详情、登录、注册。支持 zh/en 双语切换，支持 CNY / USD 双币种切换。

参考页面（已保存于 `html/`）：
- 首页：`Superbuy - 专业淘宝代购转运平台 _ 海外华人留学生代购首选.html`、`Superbuy _ 专业中国代购·国际转运·跨境电商服务平台.html`
- 商品详情：`小众设计项链男士潮牌双层轻奢秋冬毛衣链嘻哈吊坠百搭新款配饰酷 - Superbuy.html`、`AONW秋冬新款苹果刺绣连帽卫衣女宽松设计感亮片加绒开衫外套 - Superbuy.html`
- 方案详情：`方案详情 - Superbuy.html`
- 登录/注册：`欢迎登录Superbuy-海外华人网购中国商品第一品牌.html`、`欢迎注册Superbuy-海外华人网购中国商品第一品牌.html`

## 2. 技术选型
- React 18 + TypeScript + Vite
- 路由：react-router-dom v6
- UI：Ant Design v5（原站即使用 antd）
- 状态：Zustand（auth / cart / settings）
- 国际化：react-i18next（zh / en）
- Mock：MSW（Mock Service Worker），JSON 数据放 `src/mocks/data/`
- 样式：CSS Modules + antd 主题 token
- 工程化：ESLint + Prettier

## 5. 页面设计

### 5.1 首页
- 顶部栏：语言切换、货币切换、登录/注册入口（登录后显示用户菜单、购物车小红点）
- 主导航：Logo、Shop / Warehouse / Shipping / Help、搜索框（`GET /api/products/search?q=`）
- Banner 轮播（antd `Carousel`，图片来自 `html/.../*_files`）
- 热门商品网格（`GET /api/products/hot`，点击跳转 `/product/:id`）
- 服务条：代购 / 仓储 / 转运 / 售后
- 页脚静态链接

### 5.2 商品详情
基于 `小众设计项链…html`、`AONW…html` 还原：
- 左侧：图片画廊（主图 + 缩略图切换）
- 右侧：标题、`<Price>`（随货币自动换算）、SKU 选择（颜色/尺码）、数量步进器、立即购买 / 加入购物车
- Tab：商品介绍（静态 HTML 片段） / 打包方案（卡片跳转 `/solution/:id`） / 评价（Mock 列表）
- 数据：`GET /api/products/:id`

### 5.3 方案详情
还原 `方案详情 - Superbuy.html`：
- 打包选项网格：Air Column Pack / EPE Foam / Shrink Wrap 等，图标复用 `Superbuy _ 专业中国代购..._files/`
- 价格表 + 打包流程分步说明
- 数据：`GET /api/solutions/:id`

### 5.4 登录
- antd `Form`：邮箱 / 用户名 + 密码 + 记住我
- `POST /api/auth/login`（Mock：任何非空凭证均通过，返回假 token + user，写入 `auth` store）
- 提供注册入口链接

### 5.5 注册
- 表单：邮箱、密码、确认密码、国家选择（旗帜图标复用 `CN.png` / `US.png` 等）、同意协议
- `POST /api/auth/register`：基于 `users.json` 做内存级去重，返回 token，自动登录并跳首页

## 6. 国际化与货币
- `stores/settings.ts` 持久化 `locale` / `currency` 到 `localStorage`
- 汇率：固定 `{ CNY: 1, USD: 0.14 }`，符号 `¥` / `$`
- `<Price value={cny} />` 统一格式化
- 文案集中在 `i18n/zh.json` / `i18n/en.json`，按页面分组：`home.*`、`product.*`、`auth.*`、`common.*`

## 7. Mock 接口（MSW）
`src/mocks/handlers.ts`：
- `GET /api/products/hot` → `products.json` 前 12 条
- `GET /api/products/search?q=` → 按标题过滤
- `GET /api/products/:id` → 单商品详情
- `GET /api/solutions/:id` → 单方案详情
- `POST /api/auth/login` → 任意非空返回 token
- `POST /api/auth/register` → 查重后返回 token
- `GET /api/auth/me` → 根据 token 返回当前用户

`products.json` 预置 16 条商品，复用 `html/.../O1CN01*.jpg` 图片。字段：`id`、`title_zh`、`title_en`、`priceCNY`、`images[]`、`skus[]`、`descriptionHtml_zh`、`descriptionHtml_en`、`solutionIds[]`。

## 8. 交互验收清单
- [ ] 语言切换：全站文案实时刷新
- [ ] 货币切换：所有价格实时重新格式化
- [ ] 顶部搜索 → 首页网格过滤
- [ ] 点击商品卡 → 详情页加载对应 Mock 数据
- [ ] 选 SKU + 数量 → 加入购物车 → 顶部购物车徽标 +1
- [ ] 登录：任意凭证通过 → 顶部显示用户名
- [ ] 注册 → 自动登录 → 跳首页
- [ ] 退出：清除 auth store 与 localStorage

## 9. 交付步骤
1. 脚手架：`npm create vite@latest web -- --template react-ts`，安装 `antd`、`react-router-dom`、`zustand`、`react-i18next`、`i18next`、`msw`
2. 全局布局（Header / Footer）、路由、antd ConfigProvider 主题
3. i18n + settings store + `<Price>`
4. MSW + 预置 `products.json` / `solutions.json` / `users.json`
5. 首页（轮播 + 网格 + 搜索）
6. 商品详情（画廊 + SKU + 加购）
7. 方案详情
8. 登录 + 注册 + auth store
9. Loading / Empty / 响应式断点（1200 / 992 / 768）
10. `web/README.md`

## 10. 交付物
- `web/` 可运行 SPA，命令：`npm install && npm run dev`
- 本方案文档：`docs/实施方案.md`
- 无后端，无数据库；MSW 拦截所有 `/api/*`

## 11. 不在范围内
- 真实支付、真实物流计算、跨设备账户持久化
- SEO / SSR
- 管理后台
